Play against it yourself

  1. Start the game locally: npm run dev in OpenFrontIO/.
  2. Open localhost:9000, create a private lobby and copy its ID.
  3. Paste the ID here with Server set to Local and press Join lobby.
  4. Start the game once the AI shows up in your player list.

For a real openfront.io lobby, paste the lobby link. The AI joins as a normal, named player in a visible window; answer any check the site shows in that window.

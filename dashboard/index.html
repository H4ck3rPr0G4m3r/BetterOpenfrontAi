How to play against the AI yourself
  1. Start the local game: npm run dev in OpenFrontIO/.
  2. Open localhost:9000, create a private lobby, copy its ID.
  3. Paste the ID above with Server set to Local, then Join lobby. A browser window opens for the AI.
  4. When the AI shows up in your player list, start the game.

For a real openfront.io lobby, paste the lobby link. The AI joins as a normal, named player in a visible window; if the site shows a check, answer it in that window.
